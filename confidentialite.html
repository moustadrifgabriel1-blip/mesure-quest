Politique de confidentialité

Mesure Quest est une application de révision pour le brevet fédéral de spécialiste de réseau, éditée par Gabriel Moustadrif, Lussy-sur-Morges, Suisse.

Données stockées sur votre appareil

Votre progression (points, étoiles, mémoire de révision) est enregistrée uniquement sur votre appareil. Aucune inscription, aucun mot de passe, aucune adresse e-mail n\x27est demandée.

Fonction « Ma classe », facultative

Si vous rejoignez une classe avec un code, l\x27application envoie à un serveur Firebase (Google) une fiche contenant : le pseudo que vous choisissez, votre score, vos étoiles, le nombre de questions vues et ancrées, votre série de jours et la date de mise à jour. Cette fiche est visible par les personnes qui connaissent le code de la classe. Un identifiant anonyme est créé par Firebase pour distinguer votre fiche ; il ne permet pas de vous identifier. Vous pouvez quitter la classe à tout moment depuis le profil, ce qui arrête l\x27envoi.

Ce que nous ne faisons pas

Pas de publicité, pas de suivi, pas de revente de données, pas de collecte d\x27identifiants d\x27appareil. Les notifications de rappel sont programmées localement et ne quittent pas le téléphone.
